# MeepleMind 🎲🧠

MeepleMind is a small AI agent project built with [LlamaIndex](https://www.llamaindex.ai/).

The goal is to create an agent that can help choose and recommend board games based on things like:

* Number of players
* Available time
* Complexity
* Game style or mood

This project is mainly a hands-on exercise to learn how to build agents with LlamaIndex step by step.

## Tech stack

* Python
* LlamaIndex
* Anthropic Claude
* uv
